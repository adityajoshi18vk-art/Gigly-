# Gigly

Gigly is a blockchain-powered gig-economy escrow platform built on Polygon.

## Folder Structure

- `/contracts`: Hardhat project for smart contracts (Solidity). Includes OpenZeppelin and Chainlink integrations.
- `/frontend`: Next.js 14 App Router project with Tailwind CSS and Thirdweb SDK.
- `/scripts`: Directory for deployment and seed scripts.
